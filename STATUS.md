# Project Status

## Functional scope

The supplied application implements local workbook import and validation, Financial Overview, guided Scenario Analysis, an operating-result bridge, Break-Even Analysis with a sensitivity heatmap, rule-based Risk Drivers and Multi-Year Fiscal Outlook.

Future surpluses repay outstanding funding shortfall before rebuilding available fund balance. First balance and sustained recovery are separate measures. The beginning balance is optional and user-supplied.
